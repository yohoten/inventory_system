进销存管理系统

一套面向中小企业的轻量级进销存解决方案 —— 进货、出货、库存、统计一体化管理，支持 Excel 导出与打印预览。

快速开始 功能特性

核心功能

📥

进货管理

记录商品进货信息，录入后自动更新库存数量，支持历史进货记录追溯。

📤

出货管理

管理商品出库流程，出货时实时扣减库存，防止超卖。

📦

库存管理

实时查看当前库存状态，低库存自动预警（默认阈值 10 件）。

🔍

查询统计

按年份维度查询进货、出货记录与库存情况，快速掌握经营数据。

📊

数据导出

查询结果一键导出为 Excel 格式（openpyxl），便于二次分析与存档。

🖨️

打印预览

内置数据打印预览功能，所见即所得，输出规范的业务单据。

技术栈

类别说明
语言Python 3.7+
GUI 框架Tkinter / ttk
数据库SQLite3（inventory.db）
数据处理openpyxl（Excel 读写）
打包工具PyInstaller（支持单文件 / 目录模式）

快速开始

# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行主程序
python inventory_system.py

# 3. Windows 用户可直接双击 START.bat（自动检测环境并补装依赖）

# 4. 打包为独立可执行文件（可选）
python build.py --mode single --windowed --clean
默认登录：管理员账号 admin，初始密码 123456。 登录后请及时修改密码；配置文件为 system_config.json。
